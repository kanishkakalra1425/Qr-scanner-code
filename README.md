# QR Code Component

A responsive QR code component built as a solution to the **Frontend Mentor QR Code Component challenge**.

## 🛠️ Built With

* HTML5
* CSS3
* Flexbox
* Google Fonts — Outfit
* Responsive Design

## 📋 About The Project

This project is a simple QR code card designed according to the Frontend Mentor challenge.

The component includes:

* QR code image
* Heading
* Description text
* Responsive layout
* Centered card using CSS Flexbox
* Custom typography using the Outfit font

## 💡 What I Learned

While building this project, I practiced:

* Structuring a webpage using semantic HTML
* Using CSS Flexbox for alignment
* Working with `max-width`
* Using padding, margin, and `gap`
* Loading custom fonts using Google Fonts
* Making a component responsive
* Matching typography and spacing from a design
